# Verkkosivuston julkaiseminen

## Metropolian opiskelijoiden kotisivujen käyttäminen (users.metropolia.fi)

Voit julkaista verkkosivustosi Metropolian palvelimelle users.metropolia.fi-palvelun avulla seuraavasti:

1. Lataa verkkosivustosi tiedostot (all html, css and image files, etc.) to a directory named `public_html` kotihakemistossasi (HUOMAUTUS: älä poista kyseistä kansiota missään tapauksessa).
   - Pääset kotihakemistoosi kirjautumalla palvelimelle `shell.metropolia.fi` esimerkiksi SSH:n kautta. Tiedostojen siirtämiseen voit käyttää scp- tai sftp-ohjelmia (sinun täytyy ensin luoda SSH-avainpari, katso alla olevat linkit).
   - Toinen (ja aloittelijoille helpompi) vaihtoehto on käyttää <https://webdisk.metropolia.fi/> website

2. Julkaistu verkkosivustosi löytyy osoitteesta: <https://users.metropolia.fi/~yourusername>, jossa `yourusername` korvataan omalla Metropolia-käyttäjätunnuksellasi.
   - Jos käyttäjätunnuksesi on esimerkiksi "mikko", sivustosi osoite on: <https://users.metropolia.fi/~mikko>

Lisätietoja on saatavilla Metropolian Helpdeskin wikissä:

- [Home Page, Shell and MySQL Services](https://wiki.metropolia.fi/spaces/itservices/pages/8552770/Home+Page+Shell+and+MySQL+Services)
- [Creating an SSH Key Pair and Logging in on a Linux Server (shell.metropolia.fi)](https://wiki.metropolia.fi/spaces/itservices/pages/307791540/Creating+an+SSH+Key+Pair+and+Logging+in+on+a+Linux+Server+shell.metropolia.fi)
- [Webdisk Service Quick Instructions](https://wiki.metropolia.fi/spaces/itservices/pages/181375282/Webdisk+Service+Quick+Instructions)

Voit myös käyttää Helpdeskin tekoälypalvelua pyytääksesi apua: <https://mikko.metropolia.fi/>

## Muut palvelut (Metropolia/opettaja ei tue näitä)

On myös muita verkkosivustojen isännöintipalveluita (joissakin voi olla saatavilla ilmaisia vaihtoehtoja tai opiskelijapaketteja), kuten:

- Azure Static Web Apps: <https://azure.microsoft.com/en-us/services/app-service/static/>
- GitHub Pages: <https://pages.github.com/>
- Netlify: <https://www.netlify.com/>
- Vercel: <https://vercel.com/>
- Firebase Hosting: <https://firebase.google.com/products/hosting>
- Heroku: <https://www.heroku.com/>

Nämä ovat kolmannen osapuolen palveluita, ja niiden käyttämiseksi sinun täytyy luoda tili. Niillä on myös omat ohjeensa verkkosivuston julkaisemiseen, joten katso lisätietoja niiden dokumentaatiosta.

Metropolia tai opettaja eivät tue niitä, joten ongelmatilanteissa sinun täytyy ehkä pyytää apua niiden tuesta.
